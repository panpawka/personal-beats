### Why scenes are inlined, not loaded via `data-composition-src`

HyperFrames v0.4.30's `data-composition-src` mechanism doesn't paint
sub-composition content in our setup. `info` enumerates them, lint
passes, but rendered frames are blank. `bundle-scenes.mjs` works around
this by inlining each sub-comp's HTML/CSS/JS into the variant root,
rewriting `data-composition-id="X"` → `data-scene-id="X"` (so HF
doesn't treat the inner div as a clip), wrapping each scene's JS in an
IIFE (so per-scene `const ns` declarations don't collide), and
shifting all `tl.<method>(..., t)` time arguments by the scene's
parent-clip start offset. Authoring stays DRY in
`shared/compositions/`; bundling produces a flat single-file variant
each render.

## Commands

```bash
cd tools/demo-video

# author / iterate
npm run preview          # live studio (open http://localhost:3000)
npm run lint             # validates all variants
npm run inspect          # layout + overflow audit
npm run validate         # WCAG contrast + structural check

# bundle (auto-runs before lint/validate/preview/render)
npm run bundle           # CSS strip + scenes inline for all 4 variants
npm run bundle:scenes -- canonical-85s   # bundle one variant only

# render
cd variants/canonical-85s && ../../node_modules/.bin/hyperframes render \
  -q high -o /tmp/preview.mp4   # render one variant
npm run render:all       # render all 4 variants → public/demo/

# verify
cd variants/canonical-85s && ../../node_modules/.bin/hyperframes snapshot \
  --at 2.5,11,21,40,55,68,75,83  # PNG frames for review
```

## Constraints (locked in)

- HyperFrames + GSAP MUST stay dev-only. Repo-root `package.json` is
  untouched — verified against initial git status.
- No `repeat: -1` (breaks capture). Pulse-ring uses finite repeats
  computed from scene duration. The landing-loop's seamless loop is
  the embed's `<video loop>` attribute, not a GSAP repeat.
- Match real `App.css` editorial classes — every visible string from
  hand-curated Wrocław attractions, real Iran-Israel outlets (Reuters,
  BBC Persian, Times of Israel, Al-Monitor, Foreign Affairs), and real
  AI-agent refs (LangGraph 0.4.30, Claude Agent SDK 0.91.1).
- Designer dialogue locked to `tasks/demo-video-designer-voice.md`,
  derived from the actual `BEAT_DESIGNER_SYSTEM` prompt.

## Designer voice — Kasper resolution (from session)

CEO plan storyboard had Designer ask "Daily summary, or only when
something major changes?" — but the real product only supports
`on_demand` or `time_based` (cron-scheduled daily/weekly/monthly).
Cadence is locked once user picks. So the cadence-clarification line
is impossible in production. We replaced it with the authentic angle
clarification per the system prompt's own example for "Middle East
news daily" → ask which conflict or country focus. Iran-Israel
resolves "which conflict"; angle (military / diplomatic / both)
remained ambiguous and is what the Designer asks.
